# ทับกฤช Adventure V21 — ก่อน Deploy

## เพิ่มในรุ่นนี้
- หน้า Title พร้อมชื่อผู้เล่นและเบอร์โทร 10 หลัก และเช็กบ็อกซ์ยินยอมใช้ข้อมูลเพื่อติดต่อรับรางวัล
- ผู้เล่นเดิมใช้ token เดิมได้ แต่ต้องกรอกเบอร์โทรและยินยอมอีกครั้ง; ไม่เก็บเบอร์โทรใน localStorage
- หน้า Admin ดูเบอร์โทรเฉพาะผู้ดูแล และเลือกระดับความยาก ง่าย/ปกติ/ยาก แยก 5 ด่าน
- ด่าน 1: บอสพุ่งชนและยิง, ด่าน 2: หายตัวแล้วปรากฏในตำแหน่งใหม่, ด่าน 3: มุดดินแล้วโผล่โจมตี, ด่าน 4: บินขึ้นและโฉบยิง, ด่าน 5: พายุพลังบนอากาศและพุ่งชน
- เพิ่มสัญญาณเตือนจุดโจมตี, การโจมตี 2 ช่วง และความเร็ว/เลือดตามระดับจาก Admin
- ปรับไฟล์กงล้อไฟและแสงประกอบ

## สำคัญ: ห้าม Deploy V21 ก่อนอัปเกรด D1
1. Cloudflare Dashboard → Storage & Databases → D1 → ฐานข้อมูล `thapkrit-adventure` → Console
2. เปิดไฟล์ `migrations/0002_prizes_settings.sql` แล้ววาง SQL ทั้งหมด (ครั้งเดียว) แล้ว Execute
3. ตรวจว่ามีตาราง `stage_settings` และคอลัมน์ `phone`, `prize_consent_at` ใน `players`
4. อัปโหลดโปรเจกต์ผ่าน GitHub/Cloudflare โดยตรวจ Binding เดิมว่า `DB` และ `ADMIN_PASSWORD` ยังอยู่
5. ถ้าใช้ Wrangler ต้องกรอก `database_id` จริงแทน `REPLACE_WITH_D1_DATABASE_ID` ใน `wrangler.jsonc` ก่อน deploy
6. บันทึกข้อมูลเบอร์โทรของผู้เล่นโดยจำกัดสิทธิ์ Admin และกำหนดระยะเวลาจัดเก็บ/การลบตามนโยบายผู้จัด

## ทดสอบหลังอัปโหลด
- `/admin` → ลงชื่อเข้าใช้ → เลือกความยากด่าน 1–5 → บันทึก → รีเฟรชให้ค่าคงอยู่
- `/api/settings` → แสดง difficulty เช่น `[1,1,1,1,1]`
- `/` → กรอกชื่อ + เบอร์โทร 10 หลัก + ยินยอม → เริ่มเล่น; ทดสอบไม่ยินยอมแล้วสมัครไม่ได้
- ทดลองผ่านด่าน → คะแนนขึ้น Admin โดยไม่มีเบอร์โทรบน `/api/leaderboard`
- เล่นด่าน 2–5 ด้วยบัญชีทดสอบ ตรวจท่าพิเศษก่อนเปิดรางวัลจริง

ข้อจำกัด: คะแนนส่งจากไคลเอนต์ ยังไม่มีการตรวจสอบกันแก้คะแนนฝั่งเซิร์ฟเวอร์ ห้ามใช้ตัดสินรางวัลมูลค่าสูงก่อนเพิ่มการป้องกันการโกง
สถานะ: ตรวจ syntax ผ่าน แต่ยังไม่ได้ทดสอบ browser playthrough ครบทุกด่าน และยังไม่ได้ deploy ขึ้น Cloudflare
